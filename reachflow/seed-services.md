# Seed-сервисы: что из этого реально работает

Проверка от **1 сентября 2026**. Проверялось два способа: автоматический доступ (curl/HTTP из серверной среды) и
содержимое выдачи по нашим запросам. Даты и коды ответов — фактические, снятые в момент проверки.

> **Важная оговорка про 403.** «Блокирует» ниже означает «блокирует автоматический доступ из серверной среды»,
> а не «сервис бесполезен». TGStat с оплаченным API-токеном или человек в браузере получат данные нормально.
> Различайте эти два случая, когда будете принимать решение о покупке.

## Рабочие URL-шаблоны

```
# tgramsearch — основной инструмент
https://tgramsearch.com/search?query=<URL-encoded>
https://tgramsearch.com/categories/chats            # +~60 категорий: biznes-i-finansy, smm, ekonomika…
https://tgramsearch.com/join/<ID>                   # -> внутри tg://resolve?domain=<handle>

# tgstat через зеркало .com (на .ru — 403)
https://tgstat.com/ru/ratings/chats/<категория>     # business, marketing, career, sales, design, law…
https://tgstat.com/ru/chat/@<handle>/stat

# combot — недокументированный JSON
https://combot.org/api/chart/ru                     # [{"t":название,"u":хэндл,"s":размер,"l":язык}]

# сам Telegram
https://t.me/<handle>                               # og:title + счётчик = проверка живости
https://t.me/s/<handle>                             # лента канала без входа: даты постов, ссылки в тексте
```

**Главный лайфхак по tgramsearch:** индекс не семантический, он ищет по названию и описанию.
Длинные фразы («ищу подрядчика на разработку») дают пустую выдачу. Работают короткие ключи из самих названий:
`подряд`, `фриланс`, `аутсорс`, `нетворкинг`, `чат предпринимателей`, `чат бухгалтеров`.
Запрос `подряд` оказался самым урожайным по заказам, `чат предпринимателей` — по покупателям пилота.

## tgden — это конкурент, а не источник

Проверено по первоисточнику на страницах `tgden.com/en/leads` и `tgden.com/en/api-docs`:

- продукт **Lead Radar**: «AI reads live chats», заявлено **275 491 читаемых чатов**, **360 953 пойманных заявки**, **5 316 за сутки**;
- **Telegram Intent Data API**: `POST /api/v1/intent/search` с Bearer-токеном, тело вида `{"niche":"construction","geo":"thailand"}`;
- тарифы: Free 100 запросов/мес, **Pro $500/мес** (10k запросов, вебхуки), **Enterprise $5k/мес**;
- индекс: 1 883 120 каналов, ботов и чатов; на странице API заявлено 88k+ мониторимых чатов
  (расхождение с 275k на лендинге — их собственные цифры не сходятся между страницами).

Это ровно сценарий ReachFlow: чтение чатов → перехват интента → выдача заявок. Прежняя карта числила tgden
«дешёвым экспериментальным fallback» — по факту это работающий конкурент с публичным API и ценником.
Перед упаковкой пилота стоит разобрать их позиционирование: что они продают за $500/мес и чего им не хватает.

При этом как **источник** для нас tgden слаб: на 355 КБ страницы каталога всего 7 t.me-ссылок,
а поиск отдаёт ссылки вида `t.me/-100XXXXXXXXX/msgid` — числовые ID без хэндлов, в рабочие ссылки не превращаются.

## Что сработало лучше самих каталогов

Каталоги дали меньше, чем три вещи, которых в прежней карте не было вовсе:

1. **Био и описания самих чатов.** Публичное описание чата почти всегда ссылается на смежные чаты той же
   тусовки. Так найден весь кластер вокруг GetCourse и продуктовые чаты, не индексируемые поисковиками.
2. **Чтение лент через `t.me/s/<handle>`.** Работает без входа и без ключей. Так из витрины рекламной сети
   «бизнес-чатов top1» вытащены ~40 городских и страновых чатов одним запросом.
3. **Обзорные статьи** на vc.ru, habr.com, sostav.ru и README на GitHub. У vc.ru в сыром HTML ссылок нет
   (SPA), нужен рендер, но содержимое того стоит.

## Ограничения этой проверки

- Всё проверялось из серверной среды через прокси. Часть 403 — антибот-защита, а не отсутствие данных.
- Бюджет веб-поиска в сессии был исчерпан (200/200 запросов), поэтому часть работы шла только прямыми
  HTTP-запросами. Возможно, поисковая выдача дала бы дополнительные источники.
- Платные API (TGStat, Telemetr, Telemetry) не проверялись — на них нет токенов.
  Их место в приоритетах остаётся вопросом бюджета, а не доступности.
