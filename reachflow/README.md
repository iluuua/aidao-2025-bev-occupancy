# ReachFlow — рабочий каталог Telegram-сообществ

Здесь лежит то, что нужно, чтобы начать работать руками уже сегодня: список конкретных чатов,
правила захода в них и инструменты, которыми список поддерживается живым.

## Что где

| Путь | Что внутри |
|---|---|
| `catalog/shortlist.md` | **С чего начинать:** по 10 позиций на связку «сегмент × зачем идём» |
| `catalog/chats.md` | Полный каталог по сегментам, 1413 живых сообществ. Человекочитаемый |
| `catalog/gaps.md` | Чего в каталоге не хватает и где копать в следующем раунде |
| `catalog/chats.csv` | Он же машиночитаемый: для ингеста в пайплайн |
| `catalog/raw_candidates.json` | Всё найденное до фильтрации, с источником по каждой записи |
| `playbook/outreach.md` | Как брать заказы и как продавать пилот. Шаблоны сообщений |
| `playbook/scoring.md` | Скоринг: два рейтинга, признаки, формулы, полосы A/B/C |
| `playbook/compliance.md` | Правовые и платформенные ограничения. Читать до первого касания |
| `seed-services.md` | Карта seed-сервисов: что реально работает, какие URL и API живые |
| `tools/verify_tg.sh` | Проверка ссылок по t.me: жив / мёртв, тип, название, число участников |
| `tools/harvest_combot.py` | Выгрузка топа групп Combot через их JSON API |

## Два разных списка внутри одного каталога

- `use_case = take_orders` — чаты, где **постят заказы**. Туда идём за проектами.
- `use_case = sell_pilot` — чаты, где сидят **ЛПР с болью по лидам**. Туда идём продавать пилот ReachFlow.
- `use_case = both` — и то и другое.

Это не одно и то же и почти никогда не совпадает: см. два рейтинга в `playbook/scoring.md`.

## Как поддерживать каталог живым

```bash
# проверить весь каталог по t.me и увидеть, что умерло или закрылось
cut -d, -f1 reachflow/catalog/chats.csv | tail -n +2 > /tmp/handles.txt
bash reachflow/tools/verify_tg.sh /tmp/handles.txt > /tmp/verified.tsv
```

Формат вывода: `handle · status · kind · title · count · description`,
где `status ∈ {LIVE, LIVE_NOCOUNT, DEAD_OR_PRIVATE, NETFAIL}`.
`DEAD_OR_PRIVATE` означает, что публичной страницы больше нет: чат закрыли, переименовали или удалили.

Раз в месяц то же самое делает автоматическая Routine: она перепроверяет seed-сервисы,
прогоняет верификатор по каталогу и обновляет `seed-services.md`.

## Честные границы

- Полного реестра Telegram не существует. Приватные группы без опубликованного инвайта перечислить нельзя,
  и любой сервис, обещающий обратное, — красный флаг.
- Числа участников берутся с публичной страницы t.me на момент проверки и устаревают за недели.
- Каталог — это гипотезы о том, где водится спрос. Полосы A/B/C пересобираются по факту сделок, а не по размеру чата.
